# inv1zel.log — портфолио

Старый компьютер в тёмной комнате: прокрутка подводит к монитору, идёт загрузка, и открывается своя ОС нулевых с проектами, информацией «Обо мне», почтой, браузером и играми.

## Файлы

- `source/index.html` — исходник, всё в одном файле. Его же видно в превью на claude.ai.
- `source/build.py` — собирает сайт в корень репозитория.
- Корень репозитория (`index.html`, `style.css`, `scene.js`, `os.js`, `vendor/` …) — готовый сайт, его отдаёт GitHub Pages.

Тексты лежат в начале второго `<script>` в `source/index.html`: объекты `ME` (о себе), `CONTACTS` (Telegram) и `PROJECTS` (проекты). После правок выполните:

```
python3 source/build.py
```

и закоммитьте изменения.

## Выкладка

Репозиторий называется `inv1zel.github.io`, поэтому GitHub Pages включается сам и отдаёт сайт из корня ветки `main`: https://inv1zel.github.io/

## Защита в собранной версии

- Строгая Content-Security-Policy: скрипты только с самого сайта, без inline-скриптов, запрещены формы, сетевые запросы, iframe и плагины.
- Проверка целостности (SRI) для всех скриптов и стилей.
- three.js лежит внутри проекта, с внешних CDN код не грузится.
- Защита от встраивания в чужие сайты: страница остаётся пустой, если её открыли во фрейме.
- `referrer: no-referrer`, ссылки наружу с `noopener noreferrer`.
- Весь пользовательский ввод (гостевая книга, поиск, адресная строка) экранируется. Данные из `localStorage` проверяются перед использованием.
- `robots.txt` закрывает сайт от ИИ-краулеров, `404.html` для неизвестных адресов.
- Сайт ничего не собирает и никуда не отправляет. Гостевая книга, рекорд Змейки и год рождения в Сапёре хранятся только в браузере посетителя.
