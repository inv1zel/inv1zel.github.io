# iPhone Duo — концепт

Продающая страница складного iPhone в стиле промо Apple. При прокрутке живая 3D-модель раскрывается, поворачивается, складывается и меняет подсветку. Разделы: первый экран, дизайн, дисплей, шарнир, цвета, батарея, сравнение моделей.

Адрес: https://inv1zel.github.io/iphone-duo/

## Файлы

- `source/index.html` — исходник, всё в одном файле. Его же видно в превью на claude.ai.
- `source/build.py` — собирает страницу в эту папку.
- `index.html`, `style.css`, `app.js` — собранная страница, её отдаёт GitHub Pages.
- `duo.bin` — модель телефона, перегнанная из Blender в компактный бинарный формат.
- `duo-cam.jpg` — текстура блока камер.
- `vendor/` — GSAP, ScrollTrigger и Lenis. three.js берётся из общей папки `../vendor/`.

После правок в `source/index.html` выполните:

```
python3 iphone-duo/source/build.py
```

и закоммитьте изменения.

## Защита в собранной версии

Те же правила, что и у основного сайта: строгая Content-Security-Policy без inline-скриптов, SRI для всех скриптов и стилей, библиотеки лежат внутри проекта, страница не показывается внутри чужого фрейма (`../guard.js`), `referrer: no-referrer`. Сетевые запросы разрешены только к самому сайту, чтобы загрузить модель.

## Оговорка

Независимый дизайн-концепт. iPhone Duo не существует. Проект не связан с Apple Inc. и не одобрен ею. iPhone — товарный знак Apple Inc. Все цифры условные.
